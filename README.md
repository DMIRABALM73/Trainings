# Trainings

Training and study materials, supported by AI.

## Repository structure

- `docs/` - learning documents, notes, and guides.
- `training-scaffolds/` - small starter projects for hands-on practice.
- `examples/` - compact reference examples.

## Quick start

1. Read content in `docs/`.
2. Pick a scaffold in `training-scaffolds/`.
3. Build your solution in the scaffold folder and compare with examples.
